# Java Backend Developer - Dev Senior

Repositorio con los proyectos, módulos y prácticas desarrollados como parte de la formación en Dev Senior Code Academy para el rol de Java Backend Developer.

## 📂 Estructura del Repositorio

El workspace está organizado siguiendo el plan de estudios del programa:

### 🚀 Módulo 1 (m01) - Fundamentos y Capas
* **clase 1 (Proyecto Jano):** Configuración inicial de Spring Boot con Maven, gestión de propiedades y estructura base del proyecto.
* **clase 2 (Proyecto servicelayer):** Implementación de la Capa de Servicios (Service Layer) para separar la lógica de negocio.
* **clase 3 y clase 4 (Proyectos senior):** Aplicaciones orientadas a buenas prácticas de desarrollo backend avanzado con Maven y empaquetado optimizado.

### 🗄️ Módulo 2 (m02) - Persistencia y Datos
* **clase 2 (Proyecto JpaDemo):** Implementación práctica de Java Persistence API (JPA) con Spring Data, modelado de entidades, repositorios y mapeo objeto-relacional (ORM).
* **clase 3 (Proyecto senior):** Consolidación de patrones de arquitectura y servicios escalables.

## 🛠️ Tecnologías y Herramientas
* **Lenguaje:** Java
* **Framework:** Spring Boot / Spring Data JPA
* **Gestión de Dependencias:** Maven (con Maven Wrapper mvnw)
* **Control de Versiones:** Git / GitHub
